# Hospital universitario

Proyecto de una base de datos hospitalaria en **MySQL**, con 36 tablas, datos ficticios, consultas y documentación.

## Uso

1. Conéctate a MySQL desde Workbench.
2. Ejecuta [hospital_completo.sql](hospital_completo.sql) completo una sola vez para crear `hospital_universitario`.
3. Revisa [04_consultas.sql](04_consultas.sql) para consultar la base.

Requiere MySQL 8.0.16 o posterior. Probado en MySQL 8.0.45.
