# Capturas utilizadas en el manual

Son encuadres de las capturas reales de `app_hospital/capturas/`. No se modificaron los datos ni los controles. Los encuadres eliminan la franja repetida de conexión o el espacio vacío para dar más lugar a la zona que explica cada apartado.

Las capturas se renovaron el 19 de octubre de 2026 mediante las pruebas de interfaz. Utilizan el servidor local en el puerto 3307 y una base temporal UUID propia de las pruebas. La instalación aplicó la actualización 07 antes de capturar: muestra nombres completos y contactos personalizados. La contraseña permanece oculta.

El manual indica utilizar los datos propios del servidor de cada integrante. Las fechas y algunos valores del formulario de la captura son ejemplos de prueba; los pasos del texto especifican los datos del ejercicio.
