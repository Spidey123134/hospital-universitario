# Capturas utilizadas en el manual

Son encuadres de las capturas reales de `app_hospital/capturas/`. No se modificaron los datos ni los controles. Los encuadres eliminan la franja repetida de conexión o el espacio vacío para dar más lugar a la zona que explica cada apartado.

Las pruebas se hicieron en un servidor local aislado, puerto 33087 y base temporal. El manual indica utilizar los datos propios del servidor del lector. Las fechas y algunos valores del formulario de la captura son ejemplos de prueba, y los pasos del texto indican los valores del ejercicio validado.
