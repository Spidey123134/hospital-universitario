# Tutorial de la aplicación del hospital

Esta es la guía recomendada para usar el proyecto mediante ventanas, botones y formularios de Python. No hace falta escribir SQL para ver los datos, registrar pacientes ni realizar las operaciones disponibles.

- [Tutorial en PDF](tutorial_interfaz_hospital.pdf): versión para leer y compartir, con 16 páginas y seis capturas reales.
- [Tutorial editable en Word](tutorial_interfaz_hospital.docx).
- [Tutorial en texto](TUTORIAL.md).
- [Generador del Word](generar_tutorial.py): fuente para regenerarlo cuando cambie la aplicación.

Empieza por extraer **toda** la carpeta del proyecto y abrir `ABRIR_HOSPITAL.bat`, situado en la carpeta principal. La primera puesta en marcha requiere Python, MySQL Server e internet para descargar la dependencia de conexión.

El tutorial de la carpeta `tutorial/` explica el uso técnico de MySQL Workbench. Se conserva como material para desarrolladores; para la demostración de la aplicación utiliza esta nueva guía.

La [revisión de esta guía](REVISION_TUTORIAL.json) registra las 16 páginas inspeccionadas, los seis recursos gráficos y las huellas de los archivos finales. Los ejercicios de paciente, cita, consulta, receta, cobro y hospitalización se comprobaron con MySQL real mediante las pruebas de la aplicación.
